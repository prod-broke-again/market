## Настройка Google Maps

### 1. Получение API ключа

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите следующие API:
   - Maps JavaScript API
   - Geocoding API
   - Places API
4. Создайте учетные данные (API ключ)
5. Ограничьте ключ для безопасности (рекомендуется)

### 2. Настройка в проекте

Добавьте ключ в файл `.env`:

```env
GOOGLE_MAPS_API_KEY=ваш_ключ_здесь
```

## Настройка Yandex Maps

### 1. Получение API ключа

1. Перейдите в [Yandex Cloud](https://cloud.yandex.ru/)
2. Создайте платежный аккаунт (если нет)
3. Создайте сервисный аккаунт
4. Получите API ключ для JavaScript API

### 2. Настройка в проекте

Добавьте ключ в файл `.env`:

```env
YANDEX_MAPS_API_KEY=ваш_ключ_здесь
```

## Конфигурация

### Файл config/maps.php

Основные настройки карт находятся в файле `config/maps.php`:

```php
return [
    'default_provider' => env('MAPS_DEFAULT_PROVIDER', 'google'),
    
    'providers' => [
        'google' => [
            'api_key' => env('GOOGLE_MAPS_API_KEY'),
            'libraries' => ['places'],
            'language' => 'ru',
            'region' => 'RU',
        ],
        'yandex' => [
            'api_key' => env('YANDEX_MAPS_API_KEY'),
            'language' => 'ru_RU',
            'version' => '2.1',
        ],
    ],
    
    'defaults' => [
        'latitude' => 55.7558,  // Москва
        'longitude' => 37.6176, // Москва
        'zoom' => 12,
        'height' => '400px',
        'width' => '100%',
    ],
];
```

## Использование в коде

### В AddressResource

```php
use App\Filament\Forms\Components\MapPicker;

MapPicker::make('coordinates')
    ->label('Карта')
    ->mapType('google') // или 'yandex'
    ->defaultCoordinates(55.7558, 37.6176) // Москва
    ->zoom(12)
    ->height('400px')
```

### Переключение между провайдерами

В файле `.env` измените:
```env
MAPS_DEFAULT_PROVIDER=google  # для Google Maps
MAPS_DEFAULT_PROVIDER=yandex  # для Yandex Maps
```

## Функциональность

### Компонент MapPicker

- **Интерактивная карта** с возможностью клика и перетаскивания маркера
- **Автозаполнение адреса** с геокодированием
- **Обратное геокодирование** при выборе точки на карте
- **Автоматическое определение местоположения** пользователя
- **Ручной ввод координат** для точной настройки
- **Поддержка двух провайдеров** карт

### Виджет карты

- **Отображение всех адресов** на одной карте
- **Информационные окна** с деталями адреса
- **Автоматическое масштабирование** под все маркеры
- **Кэширование данных** для производительности

## Безопасность

### Рекомендации для Google Maps

1. Ограничьте API ключ по доменам
2. Установите квоты на использование
3. Используйте HTTP referrer restrictions

### Рекомендации для Yandex Maps

1. Настройте ограничения по IP
2. Установите лимиты на запросы
3. Используйте HTTPS только

## Устранение неполадок

### Карта не загружается

1. Проверьте правильность API ключа
2. Убедитесь, что API включены в консоли
3. Проверьте ограничения ключа (домены, IP)

### Ошибки геокодирования

1. Проверьте включение Geocoding API
2. Убедитесь в правильности формата адреса
3. Проверьте квоты на запросы

### Проблемы с производительностью

1. Включите кэширование в виджете
2. Ограничьте количество маркеров на карте
3. Используйте кластеризацию для большого количества точек

## Дополнительные возможности

### Кластеризация маркеров

Для большого количества адресов можно добавить кластеризацию:

```javascript
// Для Google Maps
const markerClusterer = new MarkerClusterer(map, markers, {
    imagePath: 'https://developers.google.com/maps/documentation/javascript/examples/markerclusterer/m'
});
```

### Кастомные маркеры

Можно настроить внешний вид маркеров:

```php
MapPicker::make('coordinates')
    ->customMarker('path/to/marker.png')
    ->markerSize(32, 32)
```
