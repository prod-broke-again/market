Современный маркетплейс, построенный на Laravel, предназначенный для взаимодействия покупателей и продавцов через систему заявок и откликов.

---

## 🚀 О проекте

Проект представляет собой платформу, где покупатели могут размещать запросы (заявки) на товары или услуги, а продавцы — отправлять на них свои предложения (отклики). Вся дальнейшая коммуникация происходит в изолированных чатах.

**Ключевые особенности:**
-   **Система Заявки/Отклики**: Основная бизнес-логика построена вокруг создания заявок покупателями и откликов от продавцов.
-   **Ролевая модель**: Четкое разделение пользователей на Покупателей (`buyer`), Продавцов (`seller`) и Администрацию (`super_admin`).
-   **Магазины и Товары**: Продавцы могут создавать собственные витрины (магазины) и управлять своими товарами.
-   **Панель администратора**: Мощная и гибкая админ-панель на базе **Filament** для управления всеми аспектами платформы.

## 🛠 Стек технологий

-   **Бэкенд**: Laravel 11, PHP 8.3
-   **Админ-панель**: Filament 3
-   **База данных**: MySQL
-   **Авторизация и права**: `spatie/laravel-permission` и `bezhansalleh/filament-shield`
-   **Фронтенд (в планах)**: Vue.js, Vite, TailwindCSS
-   **Real-time (в планах)**: Laravel Echo, Pusher / Soketi

## ✅ Текущий прогресс (Что уже сделано)

1.  **Проектирование архитектуры**:
    -   Разработана структура базы данных на основе анализа бизнес-логики.
    -   Созданы все необходимые миграции для сущностей: `users`, `users_info`, `shops`, `products`, `categories`, `customer_requests`, `responses`, `chats`, `chat_messages` и др.

2.  **Модели Eloquent**:
    -   Созданы все модели с корректно настроенными связями (`hasMany`, `belongsTo`, `morphMany` и т.д.).
    -   Модели типизированы с использованием современных возможностей PHP.

3.  **Панель администратора на Filament**:
    -   Установлена и настроена админ-панель Filament.
    -   Созданы ресурсы для всех ключевых моделей (`User`, `Shop`, `Product`, `Category`, `CustomerRequest`, `Response`).

4.  **Система ролей и прав (RBAC)**:
    -   Интегрирован пакет `spatie/laravel-permission` для управления ролями.
    -   Интегрирован плагин `filament-shield` для удобного управления правами через админ-панель.
    -   Настроены политики, ограничивающие доступ:
        -   Покупатели (`buyer`) не имеют доступа в админ-панель.
        -   Продавцы (`seller`) видят и управляют **только своими** данными (магазинами, товарами и т.д.).
        -   Администраторы (`super_admin`) имеют полный доступ.

5.  **Сидеры для начальных данных**:
    -   Создан сидер `RolesAndAdminSeeder` для автоматического создания ролей (`seller`, `buyer`) и пользователей.
    -   Настроен `ShieldSeeder` для создания роли `super_admin` и всех необходимых разрешений.

## ⚙️ Установка и запуск

1.  **Клонировать репозиторий**:
    ```bash
    git clone https://github.com/prod-broke-again/market.git
    cd market
    ```

2.  **Установить зависимости**:
    ```bash
    composer install
    npm install
    ```

3.  **Настроить окружение**:
    -   Скопировать `.env.example` в `.env`: `cp .env.example .env`
    -   Сгенерировать ключ приложения: `php artisan key:generate`
    -   Настроить подключение к вашей базе данных в файле `.env`.

4.  **Запустить миграции и сидеры**:
    > **Внимание!** Эта команда полностью очистит вашу БД и заполнит ее тестовыми данными.
    ```bash
    php artisan migrate:fresh --seed
    ```

5.  **Запустить сервер разработки**:
    ```bash
    php artisan serve
    ```

6.  **Войти в админ-панель**:
    -   **URL**: `http://localhost:8000/admin`
    -   **Логин**: `admin@admin.com`
    -   **Пароль**: `password`
